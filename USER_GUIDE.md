# E-commerce Platform: User Guide

## Dashboard Overview

Your new dashboard provides a complete view of your store's performance with modern, intuitive widgets.

### Key Metrics (Top Section)
Shows your 4 most important metrics:
- **Total Revenue**: Your overall sales income
- **Total Orders**: Number of orders placed
- **Total Products**: Products in your catalog
- **Active Customers**: Number of active buyers

Each metric shows a trend indicator (up/down arrow) with percentage change.

### Revenue Chart
Visual monthly revenue breakdown across the last 12 months. Hover over bars to see exact values. The gradient blue bars make it easy to spot your best-performing months.

### Recent Orders
Latest orders from your customers, displaying:
- Customer name
- Order date
- Order total
- Order status (Completed, Pending, Cancelled)

Click "View all orders" to see the complete order history.

### Order Status Overview
Quick summary of your orders by status:
- **Completed** (green): Orders that have been fulfilled
- **Pending** (blue): Orders awaiting processing
- **Cancelled** (red): Orders that were cancelled

### Top Products
Your top 5 products ranked by stock levels, showing:
- Product rank (numbered 1-5)
- Product name
- Current stock level
- Trending indicator

## Product Management

### Adding a New Product

1. Click **"Add Product"** button on the Products page
2. Fill in **General Information**:
   - Product name (required)
   - Product description
3. Upload product **image**:
   - Drag and drop an image file, or
   - Click to browse from your computer
   - Supported formats: JPG, PNG, WebP
   - Max file size: 5MB
   - See file size and name after upload
4. Set **Pricing & Inventory**:
   - Price: Base product price
   - Sale Price (optional): Discounted price
   - Stock: Available quantity
5. (Optional) Add **Variants**:
   - Click "Add variant" for different versions (colors, sizes, etc.)
   - Set variant-specific pricing and stock
   - Remove unwanted variants with the trash icon
6. Click **"Save Product"** to complete

### Editing a Product

1. Go to **Products** page
2. Find the product you want to edit
3. Click the **edit button** (pencil icon)
4. Update any fields in the dialog:
   - Name, description, status
   - Add, edit, or remove variants
5. Click **"Save changes"**
6. Success message confirms the update

### Understanding Product Variants

Variants let you manage different versions of the same product:
- **Color variants**: Red, Blue, Green (each with own price/stock)
- **Size variants**: S, M, L, XL (each with own stock)
- **Combined**: Red-Small, Blue-Large (maximum flexibility)

Each variant has:
- Unique name (e.g., "Red / Medium")
- SKU (optional product code)
- Individual price
- Individual sale price
- Individual stock quantity

## Image Upload Best Practices

### Image Requirements
- **Format**: JPG, PNG, or WebP recommended
- **Size**: Keep under 5MB (compress large files)
- **Dimensions**: 
  - Minimum: 400x400 pixels
  - Recommended: 1200x1200 pixels for best quality
- **Quality**: Clear, well-lit product photos

### Before Upload
- Image preview shows before saving
- Check file size in MB
- Verify the correct image is selected
- Remove unwanted images with the X button

### Troubleshooting Upload Issues

**"File size must be less than 5MB"**
- Your image is too large
- Compress using online tools or photo editor
- Recommended: Use TinyPNG or similar service

**"Please select an image file"**
- File type is not supported
- Try: JPG, PNG, or WebP format
- Avoid: PDF, GIF, or other formats

**Upload seems slow**
- Check internet connection
- Large files take longer to upload
- Try a smaller/compressed version

## Troubleshooting

### Products Not Showing
- Check if products are marked as "ACTIVE"
- Ensure image uploaded successfully
- Try refreshing the page
- Check browser console for errors

### Form Won't Submit
- Check for error messages in red
- Ensure required fields are filled
- Verify image is uploaded (if needed)
- Check internet connection

### Dashboard Not Loading
- Refresh the page
- Check internet connection
- Clear browser cache
- Try a different browser

### Slow Performance
- Close other browser tabs
- Check internet connection speed
- Refresh the page
- Contact support if persists
